  AI-Powered Fitness Tracking Web Application
</h3>

<br/>

Track Fit is a modern AI-powered fitness tracking platform designed to help users maintain a healthier lifestyle by monitoring fitness, nutrition, and daily activities in one place.

The application enables users to:
- Track calories consumed
- Track calories burned
- Set daily fitness goals
- Monitor workout activities
- Manage personal fitness progress

One of the key highlights of Track Fit is its AI-powered food tracking system. Users can upload food images directly from their browser, and Google Gemini AI automatically analyzes the food, estimates calorie values, and stores the information in the tracking dashboard.

Track Fit integrates Google Gemini AI to provide an intelligent food tracking experience.

Users can simply upload a food image, and the AI system automatically:
- Detects the food item
- Estimates calorie information
- Saves the analyzed data into the tracking section

This creates a smart, seamless, and modern calorie tracking experience.

# 🚀 Getting Started

Follow these steps to run Track Fit locally on your system.

---

# ⚛️ Start Frontend (Client)

Move to the client folder:

```bash
cd client
```

Install dependencies:

```bash
npm install
```

Run the frontend server:

```bash
npm run dev
```

Frontend will run on:

```bash
http://localhost:5173
```

---

# 🚀 Start Backend (Server)

Open a new terminal and move to the server folder:

```bash
cd server
```

Install dependencies:

```bash
npm install
```

Run the backend server:

```bash
npm run develop
```

Backend will run on:

```bash
http://localhost:1337
```

---

# 🔑 Environment Variables

Create a `.env` file inside the client folder and add:

```env
VITE_GEMINI_API_KEY=YOUR_GEMINI_API_KEY
```
